# Brand Spec

## Product name

SkyeForge Visual Engine

## Parent brand

Skyes Over London

## Operator signature

kAIxU Operator Build

## Visual rules

- black glass background
- acid-lime primary accent
- violet/cyan glow field
- no boxed logo container
- compact operator badge
- direct language, no fake SaaS claims

## Client-facing language

Use:

- Visual workflow engine
- AI media generation workspace
- Image, video, inpainting, and workflow automation
- Powered by Skyes Over London

Avoid:

- Saying Netlify hosts the GPU backend
- Saying models are included if they are not
- Saying every model is commercial-safe without checking license
